# AMR-Insight

**Antimicrobial Resistance Data Analysis & Prediction Project**

AMR-Insight is a step-by-step bioinformatics project focused on analyzing antimicrobial resistance (AMR) data using Python and data analysis techniques.

The project is being developed incrementally, starting with exploratory AMR data analysis and gradually progressing toward statistical analysis, genomic data integration, machine learning, and predictive modeling.

## Current Version

### V0.1 — Basic AMR Analysis

The first version focuses on exploratory analysis of antimicrobial susceptibility testing (AST) data.

### Analyses performed

* Identification of antibiotics in the dataset
* Calculation of resistance rates for each antibiotic
* Calculation of susceptibility rates
* Calculation of intermediate phenotype rates
* Comparison of antibiotic resistance profiles
* Analysis of resistance patterns across samples
* Correlation analysis between antibiotic resistance patterns
* Distribution of the number of resistant antibiotics per sample
* Generation of resistance profiles for individual samples

## Data Source

The dataset was obtained from the **NCBI Pathogen Detection Antimicrobial Susceptibility Testing (AST) data**.

Data source:

https://www.ncbi.nlm.nih.gov/pathogens/ast/

The raw dataset is not included in this repository.

## Development Roadmap

The project will be developed through several stages:

* **V0.1** — Basic AMR analysis
* **V0.2** — Data cleaning and advanced visualization
* **V0.3** — Statistical analysis
* **V0.4** — Genomic and AMR gene data integration
* **V0.5** — Machine learning
* **V0.6** — Deep learning and API development
* **V1.0** — AMR analysis and prediction platform

## Goal

The long-term goal of AMR-Insight is to combine microbiology, bioinformatics, data science, and machine learning to develop tools for analyzing and predicting antimicrobial resistance patterns.
